# 115-1 團體諮商 AI Agent 部署與設定說明

這份文件協助教師把專案放到 GitHub、連接 Google Sheets、設定 Gmail OTP，並部署到 Streamlit Community Cloud。學生不需要接觸教師的寄件信箱或 Google Sheets 憑證；每位學生只需準備學校 Email 與自己的 Gemini API Key。

## 一 準備項目

部署前需要：

1. 一個 GitHub Repository。
2. 一份空白 Google 試算表。
3. 一個已啟用 Google Sheets API 與 Google Drive API 的 Google Cloud 專案。
4. 該專案的 Service Account JSON 金鑰。
5. 一個啟用兩步驟驗證的 Gmail，以及 Gmail App Password。
6. 一個 Streamlit Community Cloud 帳號。

## 二 放到 GitHub

1. 解壓縮專案。
2. 在 GitHub 建立新的 Repository。
3. 把解壓縮後資料夾中的所有檔案上傳到 Repository 根目錄。
4. 確認沒有上傳 `.streamlit/secrets.toml`。`.gitignore` 已預設排除它。
5. 可以上傳 `.streamlit/secrets.toml.example`，因為其中只有欄位範例。

## 三 建立 Google Sheets 後台

1. 新增一份空白 Google 試算表。
2. 從網址取得 Spreadsheet ID：`https://docs.google.com/spreadsheets/d/這一段就是ID/edit`。
3. 到 Google Cloud 建立 Service Account 並下載 JSON 金鑰。
4. 在試算表按「共用」，把 Service Account JSON 內的 `client_email` 加為「編輯者」。
5. 把 Spreadsheet ID 與 JSON 欄位填入 Streamlit Secrets。

程式第一次連線時會自動建立五張工作表：

- `Sessions`
- `ChatLogs`
- `StageSummaries`
- `Assessments`
- `SeriesStates`

也可在本機先執行：

```powershell
python scripts\init_google_sheets.py
```

## 四 設定 Gmail OTP

1. 寄件 Gmail 必須先啟用兩步驟驗證。
2. 在 Google 帳戶的「應用程式密碼」建立一組密碼。
3. 把 Gmail 與 16 位應用程式密碼填入 `[email]`。
4. 不要填一般 Gmail 登入密碼。

OTP 預設 10 分鐘有效、最多輸錯 5 次、60 秒後才能重寄。OTP 不會寫入 Google Sheets。

## 五 填寫 Streamlit Secrets

打開 `.streamlit/secrets.toml.example`，複製全部內容到 Streamlit Community Cloud 的 App Settings → Secrets，再逐項改成真實值。

必要設定包括：

- `teacher_test_emails = ["ryanhsiao89@gmail.com"]`
- `participant_salt`：至少 32 字元的私密隨機字串，設定後不要更換；更換會使同一 Email 產生不同匿名代碼。
- `course_passcode`：可留空；有值時學生開始練習前必須輸入。
- `admin_passcode`：教師後台密碼。
- `sender_email` 與 `app_password`。
- `spreadsheet_id`。
- 完整 `gcp_service_account` 欄位。

`private_key` 必須保留：

```toml
private_key = """-----BEGIN PRIVATE KEY-----
中間完整內容
-----END PRIVATE KEY-----
"""
```

## 六 部署 Streamlit

1. 在 Streamlit Community Cloud 選擇 New app。
2. 選擇 GitHub Repository 與 Branch。
3. Main file path 填 `app.py`。
4. 在 Advanced settings 貼入 Secrets。
5. 按 Deploy。

部署完成後依序測試：

1. `@hcu.edu.tw` 學生信箱能收 OTP。
2. `ryanhsiao89@gmail.com` 能作為教師例外信箱收 OTP。
3. 其他 Gmail 無法登入。
4. 學生自己的 Gemini API Key 可產生回應。
5. 結束 Opening 後可接續 Formation，且成員不變。
6. 關閉瀏覽器再登入時，可從 Google Sheets 找到未完成團體。
7. 完成練習後可下載逐字稿。
8. Google Sheets 五張表皆有資料。

## 七 教師後台

Streamlit 會自動把 `pages/1_教師後台.py` 顯示為第二個頁面。輸入 `admin_passcode` 後可以：

- 檢視匿名學生數、完成階段數、逐輪紀錄數與回饋數。
- 依 participant_id 篩選。
- 下載單張 CSV。
- 下載五張表的 ZIP。

教師後台不顯示或保存學生 Gemini API Key。

## 八 常見問題

### Google Sheets 尚未連線

先確認 Spreadsheet ID、Service Account JSON 是否完整，以及試算表是否已共用給 `client_email`。未連線時系統仍可在單一執行程序內測試，但不能可靠跨日續談。

### OTP 寄送失敗

確認 Gmail 已啟用兩步驟驗證，Secrets 填的是 App Password，不是一般登入密碼；同時確認密碼中沒有多餘空白。

### Gemini 顯示 429 或 RESOURCE EXHAUSTED

這通常是學生自己的 API Key 達到模型或帳號流量限制。系統支援貼入兩把 Key 並自動切換，但不會把 Key 保存到後台。

### 模型名稱不可用

預設為 `gemini-2.5-flash`。若 Google 調整可用模型，修改 Secrets 中的 `model_name`，不必改程式碼。模型變更會記錄在 Sessions 與 Assessments。
