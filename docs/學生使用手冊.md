# 115-1 團體諮商 AI Agent 學生使用手冊

本系統讓你體驗或練習團體諮商。它是教學模擬工具，不提供心理治療、診斷或緊急危機服務。

## 開始前準備

你需要兩個不同用途的帳號：

1. `@hcu.edu.tw` 學校 Email：收取 6 位數 OTP、辨識學習紀錄與續談。
2. 個人 Gmail：登入 Google AI Studio，申請自己的 Gemini API Key。

請勿分享 API Key，也不要把它貼到班級群組、公開文件或 GitHub。

## 登入與開始

1. 輸入完整學校 Email。
2. 按「寄送 6 位數驗證碼」。
3. 到學校信箱收信，回到 Agent 輸入 OTP。
4. 貼入自己的 Gemini API Key。
5. 若課程有通行碼，輸入教師提供的通行碼。
6. 選擇開始新團體或續談既有團體。
7. 閱讀資料提醒並勾選同意。

API Key 只暫存在目前瀏覽器 Session，不會出現在逐字稿、回饋或 Google Sheets。

## 兩種學生角色

### Leader 練習模式

你是團體帶領者，系統安排三名固定 AI 成員。你可以練習開場與規範、處理沉默與防衛、促進成員間互動、深化工作、回顧與結束。

### Member 體驗模式

你是團體成員，AI Leader 依你選的學派帶領，另有兩名固定 AI 成員。過程不會顯示技巧標籤；結束後才提供體驗與參與回饋。

## 四個團體階段

- 開始期 Opening：建立安全、目的、規範與初步連結。
- 形成期 Formation：面對沉默、防衛、依賴、競爭、質疑與界線測試。
- 工作期 Working：深化核心議題、此時此刻、成員互動、衝突與修復。
- 結束期 Ending：回顧收穫、處理離別、互相回饋與後續應用。

同一團體四階段會保留相同成員、人物特質、先前摘要與未完成議題。每個階段可以一次接著完成，也可結束後改天登入，選擇「續談既有團體」。

## 學派選擇

可選不指定／整合取向，或精神分析／心理動力、阿德勒、個人中心、完形、行為治療、CBT、REBT、現實治療、SFBT、敘事治療、正向心理治療。

- Member 模式：AI Leader 依該學派示範帶領。
- Leader 模式：學生嘗試以該學派帶領，結束後回饋會檢視契合度。

## 結束與下載

完成本次練習時按「結束本階段並查看回饋」。系統會保存逐字稿、建立階段摘要與形成性回饋。你可以下載本次逐字稿；下載與續談是兩個獨立功能，沒有下載仍可在資料已成功保存時續談。

建議反思：

- 找兩句自己想保留的話。
- 找兩句想重寫的話。
- 看互動是否總回到 Leader，還是成員之間有真正回應。
- 檢查介入是否符合當時的團體階段。
- 想一個下一次只練習的焦點。

## 資料與安全

請勿輸入真實個案姓名、電話、地址、身分證字號、學號、可辨識學校或公司。若你或身邊的人正面臨立即自傷／他傷危險，請停止使用模擬系統並立即尋求真人協助；有立即危險撥 119 或 110，亦可撥衛生福利部 1925、生命線 1995 或張老師 1980。
