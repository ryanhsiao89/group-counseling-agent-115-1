# 115-1 團體諮商 AI Agent 功能驗收清單

## 登入與密鑰

- [ ] `@hcu.edu.tw` 可收 OTP 並登入。
- [ ] `ryanhsiao89@gmail.com` 依 Secrets 白名單可登入。
- [ ] 其他外部 Email 被拒絕。
- [ ] OTP 約 10 分鐘過期、最多錯 5 次、重寄有冷卻。
- [ ] Google Sheets、逐字稿與後台都找不到 OTP 或 Gemini API Key。

## 角色與學派

- [ ] Leader 模式為學生 Leader 加 3 名 AI 成員。
- [ ] Member 模式為學生 Member、AI Leader 加 2 名 AI 成員。
- [ ] 首頁有整合取向與 11 個指定學派。
- [ ] Member 模式 AI Leader 依學派示範，但過程不顯示技巧標籤。
- [ ] Leader 模式回饋檢視學派契合，不要求機械套用術語。

## 四階段與續談

- [ ] Opening、Formation、Working、Ending 可分別選擇。
- [ ] 完成一階段後可直接進入下一階段。
- [ ] 跨日登入可找到未完成團體。
- [ ] 同一 `group_series_id` 的成員、角色、主題與學派維持一致。
- [ ] 下一階段會帶入 stage summary、member states 與最近對話。
- [ ] Working 有較高機率出現成員對成員回應。
- [ ] Ending 會自然出現回顧、離別、收穫或未竟感受。
- [ ] Ending 完成後不再出現在可續談清單。

## 紀錄與回饋

- [ ] 每輪訊息依序出現在 ChatLogs。
- [ ] Session 的 start 與 end 都有 append-only 紀錄。
- [ ] StageSummaries 保留原始模型輸出與解析 JSON。
- [ ] Assessments 保留原始模型輸出、引用與替代回應。
- [ ] Leader 使用六向度帶領回饋；Member 不被套用 Leader 規準。
- [ ] 學生可下載當次 UTF-8 逐字稿。
- [ ] 教師後台可下載單表 CSV 與全表 ZIP。

## 安全與故障處理

- [ ] 首頁與練習頁顯示教學用途及去識別提醒。
- [ ] 明確第一人稱即時危機文字會停止一般角色回應並顯示真人資源。
- [ ] 無效或超額 API Key 可切換下一把。
- [ ] Google Sheets 暫時失敗時，學生仍看到警示且程式不直接崩潰。
- [ ] `pytest` 全部通過。
